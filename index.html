Question 02

Diagnosis

"An OOH campaign delivered zero code activations. What do you do?"
● Phase 1 — by probability & cost of verification

Diagnose, then optimize, then amplify.

Zero activations is almost always technical or tracking-related, not creative by default. I isolate the variable — testing what's free and fast before what's expensive to fix.

01

Technical audit

Does the code work? Is tracking firing? The likeliest cause and the cheapest to rule out.

02

User journey

Is the offer understood? Where is the code entered? Easy for new and existing users alike?

03

OOH audit

Location, visibility, legibility, wording, stopping power. A poorly placed billboard generates nothing.

04

Offer audit

Appeal, clarity, perceived value, profitability. Win the customer while staying viable.

Diagnose→Optimize→Amplify
Never relaunch before understanding why.

Speak exactly like them

FR + Arabic as a belonging marker (sahtein, yalla). Specific dishes — tabbouleh, manakish, kibbeh. Ramadan, Sunday meals, holidays.

ii

Ambassadors & gatekeepers

Lebanese restaurateurs, Lebanese-Ivorian influencers, community figures — co-authors of the message.

Hyperlocal presence

High-density neighborhoods — Marcory, Zone 4, Biétry. Micro-targeted OOH, community events, clubs.

Tastings, sponsored buffets at large gatherings, dedicated community promo codes.
